# HalaTuju finals pitch page

Open `index.html` in Chrome. Press **F** for fullscreen, then **→** (or Space) for the next page and **←** for the previous one. **End** jumps to the close.

18 pages. The main story is pages 1 to 13; pages 14 to 17 are marked "Q&A backup" and can be skipped with End. The "Open the app" buttons go to https://halatuju.replit.app/app. Fonts load from Google Fonts and the animation library from cdnjs, so the laptop needs internet; everything else is local.
