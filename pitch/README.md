# HalaTuju finals pitch page

Open `index.html` in Chrome. Press **F** for fullscreen, then **→** (or Space) for the next page and **←** for the previous one. **End** jumps to the close.

17 pages. The main story is pages 1 to 13 and ends with the thank-you page; pages 14 to 17 are the appendix (A1 to A4) for Q&A. The "Open the app" buttons go to https://halatuju.replit.app/app. Fonts load from Google Fonts and the animation library from cdnjs, so the laptop needs internet; everything else is local.
