# HalaTuju finals pitch page

Open `index.html` in Chrome. Press **F** for fullscreen, then **→** (or Space) for the next page and **←** for the previous one. **End** jumps to the close.

19 pages. The main story is pages 1 to 15 (architecture, tech stack, then the thank-you page); pages 16 to 19 are the appendix (A1 to A4) for Q&A. The "Open the app" buttons go to https://halatuju.replit.app/app. Fonts load from Google Fonts and the animation library from cdnjs, so the laptop needs internet; everything else is local.
