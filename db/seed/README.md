# Seed data (`db/seed/`)

Loaded by `server/lib/seed.ts` into an empty database. Every file except `knowledge.json` is optional. Sources, licences and transformations are in [`docs/DATA_SOURCES.md`](../../docs/DATA_SOURCES.md).

| File | Format | What it holds | Real or sample |
|---|---|---|---|
| `knowledge.json` | object (`occupations`, `skills`, `edges`, `requirements`, `courses`, `sectors`, `persona`, …) | The catalogue: 16 occupations, 29 skills, routes, requirements, outlook values and the demo persona, taken from the prototype | **Sample** (labelled as such in the UI) |
| `esco_map.json` | `{ occupations: {id: {uri, title, isco, onet, …}}, skills: {id: {uri, preferredLabel, description, aliases, …}} }` | Each catalogue id mapped to its closest ESCO v1.2.1 concept, with ISCO-08 and O\*NET-SOC codes and ESCO alt labels for CV matching. `match` says how close the mapping is: exact, close, nearest or none. | **Real.** 16/16 occupations and 24/29 skills mapped. 3 emerging skills and 2 skills with no ESCO equivalent keep `uri: null`. Built by `scripts/data/build_esco_map.py`. |
| `studies.json` | array of `{ occupationId, study, value, rawValue, note, sourceUrl, source }` | AI-exposure estimates per occupation for the "Studies disagree" view: ILO WP140, Anthropic Economic Index (observed exposure, and Claude usage share) and Eloundou et al. *GPTs are GPTs* | **Real.** 57 rows. A study is left out for an occupation when it has no value for that occupation's code. Built by `scripts/data/build_studies.py`. |
| `courses.json` | array of `{ skill, title, provider, url, format, formatText, hours, costRm, hrdClaimable, source, priceStated, evidence, checkedAt }` | One or two real, listed courses per skill. They replace the sample course for that skill; practice and prove tasks still come from the sample. | **Real** (`source: provider_listing`). 30 courses cover all 29 skills. Links are checked by `scripts/data/check_courses.py`. |
| `employers.json` | array of `{ name, sector, careersUrl, source, verified, requirements: [{occupationId, skillId, weight, levelNeeded, quote, sourceUrl}] }` | Two fictional employers whose extra requirements are added on top of catalogue jobs | **Sample.** The names are fictional and say "(sample)". No real company is named. |
| `dosm.json` | `{ note, licence, datasets: [{ id, title, url, page, accessed, frequency, columns, rows }] }` | Small extracts of Malaysian labour statistics: wages and wage recipients by MASCO major group, skills-related underemployment, and Penang's labour force and wages | **Real** (DOSM via data.gov.my, CC BY 4.0). The `wages_occupation` table is shown for every ESCO occupation's major group ("check any job"). Built by `scripts/data/fetch_dosm.py`. |
| `esco_full.json.gz` | `{ _meta, occupations: {id: {title, code, isco, description, alt, essential: [skillId], optional: [skillId], ilo: {group, gradient, mean, sd}}}, skills: {id: {title, description, alt, type}} }` | Every ESCO v1.2.1 occupation (3,039) and skill (13,939), English, with 126,051 essential/optional links and the ILO WP140 exposure of each occupation's ISCO-08 group (2,956). Loaded into memory by `server/services/esco.ts` | **Real** (ESCO, CC BY 4.0; ILO WP140, CC BY 4.0). Built by `scripts/data/build_esco_full.py`. |
| `esco_skill_scores.json.gz` | `{ _meta, scores: {skillId: [modelExposure, nearestCatalogueSkillId, cosine]} }` | Our exposure model's estimate for every ESCO skill (from its title, bge-m3 on RunPod), and its nearest catalogue skill. `_meta.iloAgreement` reports r = 0.79 against ILO WP140 | **Model estimates**, labelled as such. Built by `scripts/score-esco-skills.ts`. |
| `esco_onet.json.gz` | `{ _meta, occupations: {escoId: {onet, match, title, gptsBeta, aei}}, onet: {code: {title, tasks: [[text, rating, core]]}} }` | Closest O\*NET occupation per ESCO occupation (official crosswalk, 2,607 linked), its tasks with human exposure ratings (2,471 occupations, 16,411 tasks), GPTs-are-GPTs and Anthropic Economic Index scores | **Real** (O\*NET CC BY 4.0; Eloundou et al. MIT; AEI CC BY). Built by `scripts/data/build_esco_onet.py`. |
| `quiz_tasks.json` | `{ _meta, tasks: {"<onet>#<i>": {esco: [escoId], cat: [[skillId, cosine], …], en?, ms?}} }` | For the no-CV quiz: each task it may show (4,017 O\*NET tasks, up to 6 per occupation) with the ESCO skills of its own occupations it uses and its two nearest catalogue skills (bge-m3 cosine), plus a short chip in plain English and Bahasa Melayu | **Real** links (O\*NET CC BY 4.0, ESCO v1.2.1); chip wording rewritten by an LLM from the task statement only. Built by `scripts/build-quiz.ts`. |
| `mycol.json` | `{ _meta, occupations: [{masco, title, new, everyEdition}] }` | Malaysia's 66 critical occupation groups (MyCOL 2024/2025, Table 7; flags from Tables 8–9) | **Real**, facts copied by hand from the published table and checked against OCR (`scripts/data/check_mycol.py`). |
| `embeddings.json` | `{ model, dims, provider, createdAt, note, vectors: {skillId: number[]} }` | Skill vectors for semantic CV matching | Computed by an embedding model (named in the file). Its `note` says how they are made and regenerated. |
| `replay_run.json` | object (`items`, `candidates`, `reviews`, …) | One recorded live market-scout run, replayed on a fresh install | **Real** run, recorded on 2026-10-22. See its `_note`. |
