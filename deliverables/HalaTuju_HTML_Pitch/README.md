# HalaTuju HTML pitch

Open `index.html` in a modern browser. The slides, animations, and screenshots work locally without a server. Links to the live app and GitHub require internet access.

## Presenting

- **Right arrow, Space, or Page Down:** reveal the next point or advance.
- **Left arrow or Page Up:** go back.
- **N:** speaker notes.
- **Q:** Q&A appendix; press again to return to the close.
- **M:** slide menu.
- **F:** fullscreen.
- Swipe left or right on a touch screen.

The main pitch is 11 slides. Three appendix slides hold stress-test, evaluation, and employer-use details for questions. Motion reduces automatically when the operating system requests reduced motion.

Content was rebuilt from the finals deck guide and the submitted PDF pitch deck. The HalaTuju brand and screenshots match the current application. Unfinished guide placeholders and unverified results were omitted or labelled as assumptions.
